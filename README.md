# Pagina Web Ludogic

Empresa de  videojuegos

Proyecto web de Jose Antonio Reyes.

## Cómo verla en el navegador
Abre el archivo `index.html` con doble clic, o con clic derecho > Abrir con > tu navegador.

## Estructura
- `data.js` — **todo el contenido editable** (textos, servicios/plantas, portfolio, contacto). Para cambiar cualquier texto, edita este fichero, no el HTML.
- `index.html` — esqueleto de la página (contenedores que `render.js` rellena con `data.js`)
- `style.css` — estilos visuales (paleta, tipografía, layout)
- `render.js` — genera el HTML de las secciones dinámicas a partir de `data.js`
- `hero3d.js` — escena 3D del hero (la puerta que se abre con el scroll)
- `parallax.js` — efecto de paralaje/descenso en la sección de plantas de servicio
- `script.js` — menú móvil y animaciones de aparición al hacer scroll
